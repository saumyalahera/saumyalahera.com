Language at a glance

Malossa reads like a sketch of a shader. Functions open with fc and close with end. The one that closes with end mf draws every pixel. The app has the full guide built in under ⌘?.

Write this · it means

fc name (int a b)(float c) … endA function. Parameters are grouped by type.
end mfMarks the main function, the shader that draws each pixel.
float a b c;Declares several variables at once.
loop i 0 to 10 · loop x > 1Count up, count down, or loop while a condition holds.
array a; scan a 10; a->3Arrays, and reading or writing an element.
-6 -bl -eComment out the next 6 lines, up to the next blank line, or up to the next end.
pref 2(x)Calls function number 2.
wc fc lc fs gp gmfWord count, function count, line count, function size, function number, main function name.
print x;Shows the value of x at the pixel under your mouse.
time resolution pixel uvValues the app gives every shader.

Install

Malossa is a free download for macOS.

1

Download the latest Malossa.dmg from Releases.

2

Open the DMG and drag Malossa into Applications.

3

Launch Malossa from Applications and start a new project with ⌘N.

If macOS says Malossa “can’t be opened”, it’s because the app isn’t signed with an Apple Developer ID yet. You only need to do this once:
  1. Try to open Malossa, then click Done on the warning.
  2. Open System Settings → Privacy & Security.
  3. Scroll to the message about Malossa and click Open Anyway.
  4. Confirm with your password or Touch ID, then click Open.
